# Дурак DS

Игра «Дурак» для Nintendo DS в стиле швейцарского минимализма: плоские 3D-карты, выбор карт стилусом.

## Что в репозитории

| Файл | Что это |
|---|---|
| `prototype-durak-swiss3d.jsx` | Браузерный прототип (React + three.js). Режимы: обычный, подкидной, переводной; 1–3 бота; режим «жульничество» |
| `main.c`, `Makefile` | Порт на C / libnds. Пока каркас: рука из 3D-карт на нижнем экране, выбор стилусом, статус на верхнем |
| `.github/workflows/build.yml` | Облачная сборка `.nds` через GitHub Actions |

## Сборка

Собирается автоматически при каждом пуше: вкладка **Actions** → последний запуск → **Artifacts** → `durak-ds`.

Релиз: **Releases** → **Draft a new release** → создать тег `v0.1` → **Publish release**. Готовый `.nds` появится в **Assets** релиза.

## Запуск

Скопировать `durak.nds` на microSD (R4 / TWiLight Menu++) или открыть в эмуляторе (например, melonDS).

## Заметки по архитектуре

- У DS один аппаратный 3D-движок, он рисует только на одном экране. Поэтому рука (3D, касание) на нижнем экране, а стол сверху будет 2D-спрайтами.
- Масти в Swiss-стиле строятся из полигонов, ранги будут битмап-шрифтом.
